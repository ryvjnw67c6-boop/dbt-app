# DBT: Deb's Board Training

A free study app for the ASWB Clinical licensing exam (2026 content outline): timed practice exams, drills, strategy lessons and flashcards.

All questions are **original practice items** written for this app. They are not ASWB questions and are not endorsed by ASWB.

Open the app: the GitHub Pages site for this repository (index.html). Progress is saved in your browser on each device, and you can export or import it from Settings.
